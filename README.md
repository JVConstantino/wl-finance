# 💰 FinançasPro - Gestão Financeira Inteligente

Aplicação moderna de gestão financeira pessoal e familiar construída com **React**, **Vite**, **Tailwind CSS** e **Lucide Icons**, com suporte a inteligência artificial para categorização e análise de gastos.

---

## ✨ Principais Funcionalidades

- 📊 **Dashboard Completo**: Visão geral de contas correntes, carteiras e cartões de crédito.
- 💳 **Gestão de Cartões de Crédito**: Acompanhamento de fatura e botão de quitação automática via transferência.
- 📈 **Análise Visual & Gráficos**: Gráficos Donut SVG com detalhamento percentual de despesas e patrimônio investido.
- 🎯 **Metas e Limites Orçamentários**: Definição de tetos mensais por categoria com indicadores visuais de progresso.
- 🔄 **Contas Fixas & Assinaturas**: Previsão de custo recorrente mensal e anual (Netflix, Spotify, etc.).
- 🚀 **Máquina do Tempo**: Projeção preditiva do saldo financeiro para os próximos 6 meses.
- 📅 **Agenda e Calendário Financeiro**: Visualização de fluxo de caixa por dia do mês.
- 🤖 **Copiloto FinBot com IA**: Chatbot inteligente para registro rápido por texto e leitura visual de notas/recibos fiscais via câmera (Google Gemini API).
- 👨‍👩‍👧‍👦 **Modo Família & Casal**: Conexão com código de sincronização compartilhado.
- 🌗 **Dark Mode / Light Mode**: Alternância de tema com transições suaves.
- 💾 **Persistência Local Automática**: Salva todos os dados no `localStorage` do navegador com segurança e velocidade.
- 📥 **Exportação de Relatórios**: Download de extratos mensais em formato CSV.

---

## 🛠️ Tecnologias Utilizadas

- **React 18**
- **Vite**
- **Tailwind CSS**
- **Lucide React** (Ícones)
- **Google Gemini API** (Opcional, para recursos avançados de IA)

---

## 🚀 Como Executar o Projeto

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/JVConstantino/wl-finance.git
   cd wl-finance
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Acesse no navegador:**
   [http://localhost:3000](http://localhost:3000)

---

## 📦 Build para Produção

```bash
npm run build
```
Os arquivos otimizados serão gerados na pasta `dist/`.
